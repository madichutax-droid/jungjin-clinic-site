# 치료 후기 — 켜는 법

2026-09-17 · 이 파일은 홈페이지에 공개되지 않습니다.

---

## 어떻게 돌아가나

- **후기는 원장님이 올리십니다.** 환자분은 쓰지 못합니다.
- **제목·분류·날짜는 누구나 봅니다.** 누르면 로그인 화면으로 갑니다.
- **글 내용은 로그인해야** 보입니다. 로그인 안 한 사람에게는 본문이 한 글자도 가지 않습니다.
- 검색엔진에는 걸리지 않습니다.
- 가입할 때 **아이디 · 비밀번호 · 이름 · 휴대폰 · 생년월일 · 이메일**을 받습니다.
  이름과 휴대폰을 받는 것이 중요합니다 — 원장님이 환자명부와 대조하실 수 있어야
  '아무나'가 아니라 '우리 환자'가 되고, 그래야 회원 전용으로 둔 의미가 삽니다.

## 왜 로그인을 걸었나

의료법 제56조는 환자 치료경험담을 광고로 보고 금지합니다.
어기면 벌금이나 업무정지가 나옵니다.

법이 보는 기준은 **"아무나 볼 수 있느냐"** 입니다. 그래서 회원만 보게 막고,
네이버·구글 검색에도 안 걸리게 해 두었습니다.

완전히 안전하지는 않습니다. 회원제로 해도 단속된 곳이 있습니다.
**위험을 크게 줄인 것이지 없앤 것은 아닙니다.**

## ① 후기를 담아 둘 곳 만들기 (10분)

글을 저장해 둘 곳이 필요합니다. 무료입니다.

2. **New project** 를 누릅니다
   - **Name** — `jungjin` 아무거나
   - **Database Password** — 아무렇게나 길게. **적어 두십시오.** 다시 못 봅니다
   - **Region** — 목록에서 **Northeast Asia (Tokyo)** 를 고르십시오.
     다른 걸 고르시면 개인정보처리방침을 고쳐야 합니다

1. 왼쪽 메뉴에서 **SQL Editor** 를 누릅니다

3. 빈칸에 붙여넣고 오른쪽 아래 **Run** 을 누릅니다
4. 초록색으로 `Success` 가 뜨면 됩니다

## ③ 열쇠 두 개 가져오기 (2분)

1. 왼쪽 맨 아래 **Project Settings** → **API**
2. 두 개를 복사해서 어디든 적어 두십시오
   - **Project URL** — `https://어쩌구.supabase.co`
   - **anon public** — `eyJ...` 로 시작하는 긴 글자, 또는
   - **Publishable key** — `sb_publishable_...` (지금 쓰고 있는 것입니다)

> **`service_role` 이라고 적힌 것은 절대 가져오지 마십시오.**
> 그건 마스터키입니다. 홈페이지에 넣으면 후기가 전부 공개됩니다.
> 바로 위에 있는 **anon public** 이 맞습니다.

## ⑤ 원장님 계정 등록 (마지막, 꼭 하셔야 합니다)

**이걸 안 하면 원장님도 글을 못 올리십니다.**

1. https://jungjinhani.com/login.html → **회원가입**
   원장님 아이디를 정하십니다 (영문 소문자·숫자 4~20자, 예: `yangjj`)
2. 가입하시면 바로 로그인됩니다
3. Supabase → **SQL Editor** → 아래를 붙여넣고 **아이디만 바꿔서** Run

```sql
insert into public.authors (user_id)
select user_id from public.profiles where username = 'yangjj'
on conflict do nothing;

select p.username as "아이디", p.full_name as "이름",
       (a.user_id is not null) as "글올리기권한"
  from public.profiles p
  left join public.authors a on a.user_id = p.user_id;
```

4. 홈페이지에서 새로고침하면 **"후기 올리기"** 칸이 생깁니다

## 회원이 아이디나 비밀번호를 잊으면

**2026-09-18 부터 회원이 스스로 합니다.** 전화 주실 일이 없어졌습니다.

로그인 화면 아래 `아이디 찾기 · 비밀번호 재설정` 으로 들어갑니다.

| | 무엇이 맞아야 하나 | 결과 |
|---|---|---|
| 아이디 찾기 | 이름 · 휴대폰 · 생년월일 (셋) | `yan***` 처럼 앞 세 글자만 보여 줍니다 |
| 비밀번호 재설정 | 거기에 아이디 · 이메일까지 (다섯) | 그 자리에서 새 비밀번호로 바뀝니다 |

가입할 때 적은 것과 **전부** 맞아야 합니다. 하나라도 다르면 무엇이 틀렸는지
알려 주지 않습니다 — 알려 주면 남의 정보를 맞춰 보는 데 쓰입니다.

아이디를 통째로 보여 주지 않는 것도 같은 이유입니다. 이름과 번호를 아는
사람이 남의 아이디를 알아내지 못하게 앞 세 글자만 보냅니다.

### 이걸 켜려면 — Netlify 에 열쇠 하나 (2분) ★

**이 단계를 안 하면 화면은 나오는데 "아직 준비되지 않았습니다" 만 뜹니다.**

회원 명부는 본인과 원장만 볼 수 있습니다. 비밀번호를 잊은 분은 로그인을
못 하니 명부를 볼 수 없고, 그래서 대조를 **서버에서** 합니다. 그 서버가
명부를 읽으려면 `service_role` 열쇠가 필요합니다.

1. Supabase → **Project Settings** → **API** → **service_role** 복사
2. Netlify → 이 사이트 → **Site configuration** → **Environment variables**
3. **Add a variable**
   - Key: `SUPABASE_SERVICE_ROLE`
   - Value: 복사한 열쇠
4. **Save** → **Deploys** 에서 **Trigger deploy** 를 한 번 눌러 주십시오
   (환경변수는 새로 배포해야 함수에 들어갑니다)

> **이 열쇠는 Netlify 에만 넣습니다.** `partials.py` 나 홈페이지 코드에
> 넣으면 후기가 전부 공개됩니다 — 정책을 그냥 지나가는 마스터키입니다.
> Netlify 환경변수는 홈페이지 소스에 나오지 않습니다.

그리고 `schema.sql` 을 **다시 한 번 실행**하십시오 (7번 표와 8번 권한이
새로 생겼습니다). 여러 번 실행해도 괜찮게 적어 두었습니다.

> **8번을 빼먹으면 "지금은 확인할 수 없습니다" 만 뜹니다.**
> `service_role` 은 RLS 정책은 지나가지만 표를 볼 권한은 따로 받아야 합니다.
> 2026-09-19 에 이것 때문에 한 번 막혔습니다.
>
> 지금 어떤 상태인지는 이 주소로 확인하실 수 있습니다 —
> <https://jungjinhani.com/.netlify/functions/recover?check=1>
> `명부: 열립니다` · `기록표: 열립니다` 두 줄이 나오면 다 된 것입니다.
> 열쇠 값이나 회원 정보는 여기에 나오지 않습니다.

### 원장님 계정은 여기서 못 바꿉니다

일부러 막아 두었습니다. 원장 계정은 후기를 올리고 지울 수 있어서, 이름·번호·
생일을 아는 사람에게 넘어가면 피해가 다릅니다. 원장님 비밀번호를 바꾸실 때는
Supabase → **Authentication** → **Users** → 그 계정에서 하십시오.

### 수상한 시도가 있었는지 보기

한 시간에 같은 IP 가 10번, 같은 번호로 5번 틀리면 막습니다.
시도는 `recovery_log` 에 남습니다 (휴대폰 뒤 4자리까지만 남깁니다).

```sql
select at as "때", kind as "무엇", ok as "성공", hint as "번호뒤4", ip
  from public.recovery_log order by at desc limit 50;
```

가끔 지우십시오.

```sql
delete from public.recovery_log where at < now() - interval '30 days';
```

### 그래도 메일 방식이 더 안전합니다

지금은 **아는 것으로만** 확인합니다. 이름·번호·생일·이메일을 아는 사람이라면
남의 계정을 가져갈 수 있습니다. 가족이나 가까운 사람이 그렇습니다.

메일로 링크나 인증번호를 보내는 쪽이 한 단계 더 안전한데, 지금 구조에서는
못 합니다 — 아이디로 로그인하려고 인증 주소를 가짜로 만들어 두어서 메일이
갈 곳이 없습니다. 메일 보내는 곳(무료 서비스가 있습니다)을 붙이시면 그때
인증번호 단계를 지금 것 위에 얹을 수 있습니다. 말씀해 주십시오.

## 켜지고 나면 — 후기 올리는 법

1. 홈페이지 → 치료 후기 (로그인된 상태)
2. **제목**을 네 조각으로 고르고 적습니다
   - **분류** — 진료 갈래에서 고릅니다 (메뉴에 있는 진단명 그대로입니다)
   - **나이** — `66`
   - **성별** — 여 / 남
   - **성함 표기** — `차OO님` 처럼. **실명은 쓰지 마십시오**

   적으시는 대로 아래에 `척추관협착증, 66세, 여, 차OO님` 으로 미리 보입니다.
3. **내용** — 붙여넣거나 적습니다 (4000자까지)
4. **올리기**

회원 화면에서는 분류 탭으로 거르고, 열 개씩 넘겨 봅니다.
제목을 누르면 그 자리에서 내용이 펼쳐집니다.

글이 하나도 없는 분류는 탭에 나오지 않습니다 — 눌러도 빈 화면만 나오니까요.

"완치" 같은 말이 들어 있으면 올라가지 않고 어느 말인지 알려 줍니다.
그 말만 빼고 다시 올리시면 됩니다.

### 고치기

제목을 눌러 펼치면 아래에 **고치기** 와 **지우기** 가 있습니다.

**고치기**를 누르면 글쓰기 칸으로 내용이 올라옵니다. 고치고 **고쳐서 올리기**.
그만두시려면 **취소**.

사진은 이렇게 됩니다.

- 그냥 두면 — 붙어 있던 사진이 그대로 남습니다
- 새 파일을 고르면 — 새 사진으로 바뀌고 **옛 사진은 지워집니다**
- **사진 빼기**를 누르면 — 사진이 없어집니다

붙어 있던 사진에 얼굴을 더 가리셔야 하면, **새 파일로 다시 올리십시오.**
이미 올라간 사진은 그림판으로 불러오지 않습니다.

지우실 때는 글 아래 **지우기** 를 누르십시오.

### 사진을 붙이실 때

1. **동의서를 먼저 받으십시오.** https://jungjinhani.com/consent.html 을 열어
   **인쇄하기**를 누르면 종이로 나옵니다. 환자분 서명을 받아 보관하십시오.
2. 글쓰기 칸에서 **파일 선택**으로 사진을 고릅니다.
3. 사진이 아래에 뜨면 **얼굴 위를 문지르십시오.** 그 자리가 모자이크로 가려집니다.
   잘못 칠하셨으면 **되돌리기**.
4. 가린 자국은 **그림 자체에 찍혀 나갑니다.** 올린 뒤에는 벗겨낼 수 없습니다.

### 환자분이 내려 달라고 하시면

**글을 지우십시오.** 글을 지우면 사진도 함께 지워집니다.
Supabase 에서 행만 지우시면 사진 파일이 남아 주소로 계속 열립니다.
홈페이지의 **지우기** 단추를 쓰시는 것이 안전합니다.
