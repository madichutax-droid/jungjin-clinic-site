# 치료 후기 — 켜는 법

2026-09-17 · 이 파일은 홈페이지에 공개되지 않습니다.

---

## 어떻게 돌아가나

- **후기는 원장님이 올리십니다.** 환자분은 쓰지 못합니다.
- 환자분은 **회원가입하고 로그인해야 읽을 수 있습니다.**
- 로그인 안 한 사람에게는 **한 글자도** 안 보입니다.

## 왜 로그인을 걸었나

의료법 제56조는 환자 치료경험담을 광고로 보고 금지합니다.
어기면 벌금이나 업무정지가 나옵니다.

법이 보는 기준은 **"아무나 볼 수 있느냐"** 입니다. 그래서 회원만 보게 막고,
네이버·구글 검색에도 안 걸리게 해 두었습니다.

완전히 안전하지는 않습니다. 회원제로 해도 단속된 곳이 있습니다.
**위험을 크게 줄인 것이지 없앤 것은 아닙니다.**

## ① 후기를 담아 둘 곳 만들기 (10분)

글을 저장해 둘 곳이 필요합니다. 무료입니다.

1. <https://supabase.com> 에 들어가 **Start your project** → 가입
2. **New project** 를 누릅니다
   - **Name** — `jungjin` 아무거나
   - **Database Password** — 아무렇게나 길게. **적어 두십시오.** 다시 못 봅니다
   - **Region** — 목록에서 **Northeast Asia (Tokyo)** 를 고르십시오.
     다른 걸 고르시면 개인정보처리방침을 고쳐야 합니다
3. **Create new project** → 2~3분 기다립니다

## ② 후기 담을 칸 만들기 (5분)

1. 왼쪽 메뉴에서 **SQL Editor** 를 누릅니다
2. 이 폴더의 **`schema.sql`** 파일을 열어 **전체 복사**
3. 빈칸에 붙여넣고 오른쪽 아래 **Run** 을 누릅니다
4. 초록색으로 `Success` 가 뜨면 됩니다

## ③ 열쇠 두 개 가져오기 (2분)

1. 왼쪽 맨 아래 **Project Settings** → **API**
2. 두 개를 복사해서 어디든 적어 두십시오
   - **Project URL** — `https://어쩌구.supabase.co`
   - **anon public** — `eyJ...` 로 시작하는 긴 글자, 또는
   - **Publishable key** — `sb_publishable_...` (지금 쓰고 있는 것입니다)

> **`service_role` 이라고 적힌 것은 절대 가져오지 마십시오.**
> 그건 마스터키입니다. 홈페이지에 넣으면 후기가 전부 공개됩니다.
> 바로 위에 있는 **anon public** 이 맞습니다.

## ③-2 메일 링크가 돌아올 곳 정하기 (꼭 하셔야 합니다)

**이걸 빼먹으면 가입 확인 메일의 링크가 `localhost:3000` 으로 갑니다.**
"사이트에 연결할 수 없음" 이 뜨고 가입이 안 끝납니다. 2026-09-17 에 겪었습니다.

왼쪽 메뉴 **Authentication** → **URL Configuration**

| 칸 | 넣을 것 |
|---|---|
| `Site URL` | `https://jungjinmedi.netlify.app` (끝에 `/` 없이) |
| `Redirect URLs` | `https://jungjinmedi.netlify.app/**` (별표 두 개까지) |

**Save** 를 누르십시오.

도메인이 새로 생기면 여기에도 함께 넣어야 합니다.
비밀번호 재설정이 안 된다는 문의가 오면 십중팔구 이 자리입니다.

## ④ 홈페이지에 끼우기

`_build/partials.py` 를 열어 이 두 줄을 찾아 채웁니다.

```python
SUPABASE_URL      = "여기에 Project URL"
SUPABASE_ANON_KEY = "여기에 anon public"
```

그리고 평소처럼 올립니다.

```bash
cd _build && python3 build.py
cd .. && git add -A && git commit -m "치료 후기" && git push
```

이제 메뉴에 "치료 후기" 가 생깁니다.

## ⑤ 원장님 계정 등록 (마지막, 꼭 하셔야 합니다)

**이걸 안 하면 원장님도 글을 못 올리십니다.**

1. 홈페이지 → 치료 후기 → **회원가입** 을 원장님 이메일로 하십니다
2. 메일함에서 확인 메일의 링크를 누릅니다
3. Supabase → **SQL Editor** → 아래를 붙여넣고 **이메일만 바꿔서** Run

```sql
insert into public.authors (user_id)
select id from auth.users where email = '원장님이메일@example.com'
on conflict do nothing;
```

4. 홈페이지에서 새로고침하면 **"후기 올리기"** 칸이 생깁니다

## 켜지고 나면 — 후기 올리는 법

1. 홈페이지 → 치료 후기 (로그인된 상태)
2. **쓰신 분** — `60대 · 여성` 처럼 적습니다. **실명은 쓰지 마십시오**
3. **내용** — 붙여넣거나 적습니다
4. **올리기**

"완치" 같은 말이 들어 있으면 올라가지 않고 어느 말인지 알려 줍니다.
그 말만 빼고 다시 올리시면 됩니다.

지우실 때는 글 아래 **지우기** 를 누르십시오.

### 올리기 전에 꼭

환자분께 **종이로 동의를 받아 두십시오.** 건강에 관한 내용이라
말로만 받으면 나중에 증명할 방법이 없습니다.
동의서 양식이 필요하시면 만들어 드리겠습니다.

---

## 확인 — 올리기 전에 한 번만

**로그인 안 한 사람에게 정말 안 보이는지** 보는 것입니다. 이것 하나가 전부입니다.

1. 크롬에서 **시크릿 창**을 엽니다 (`⌘ + Shift + N`)
2. 홈페이지 → 치료 후기
3. **"회원만 볼 수 있습니다"** 만 보이면 정상입니다
4. 후기 내용이 보이면 ② 를 다시 하셔야 합니다

`_build/partials.py` 에서 `REVIEWS_ON = True` 를 `False` 로 바꾸고 다시 올리면
메뉴에서 사라집니다.

## 돈

무료입니다. 후기 게시판 하나로는 무료 범위를 넘지 않습니다.
일주일 동안 아무도 안 들어오면 잠들었다가, 다음 사람이 들어올 때
몇 초 느려집니다. 개원하고 손님이 오시면 안 생기는 일입니다.
